# qol.Client.dll

The in-game panels of the QoL mod (a NativeMods client mod): buttons, keys, price lines, toasts, the alternate quality
gems panel and the Harvest panel. It asks the QoL server mod on 127.0.0.1 (its port setting, 6170 by default).
Source: `source/` beside this file (build with `dotnet build -c Release` against `LocalExile.Client.Sdk.dll`).
